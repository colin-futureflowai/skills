# Claude Code Skills Repository

This repository contains custom Claude Code skills. Each skill lives in `skills/<skill-name>/`.

## Conventions

- Every skill MUST have a `SKILL.md` as its entry point
- Rules go in `rules/*.md` inside the skill directory
- Use `templates/skill-template/` to scaffold new skills
- Skill names use kebab-case: `my-awesome-skill`
- Keep skills self-contained and independent of each other
